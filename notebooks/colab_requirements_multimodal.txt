# Pinning policy
# --------------
# Exact pins for packages Colab does not preinstall. These are ours to control
# and cannot conflict with Colab's compiled stack, so they are pinned hard to
# keep runs comparable across sessions.
#
# Floors, not pins, for numpy / scipy / torch / torchvision / matplotlib / tqdm.
# Colab preinstalls these and builds its other compiled wheels against them.
# Pinning torch especially can replace Colab's CUDA build with a wheel that does
# not match the driver, and pinning numpy can break Colab's own compiled
# packages. The numpy floor of 2.0 is deliberate: mixing numpy 2.x with wheels
# built against 1.x is what produces "_ARRAY_API not found" / "numpy.core.
# multiarray failed to import" part-way through a session.
#
# The preflight cell records the versions that actually resolved, so a run stays
# identifiable even for the floored packages.
#
# For a reproducible rerun, replace the branch below with the commit that the
# preflight cell reported for that run, e.g.
#   git+https://github.com/kevins-winter/multipose2.git@e1b998a
